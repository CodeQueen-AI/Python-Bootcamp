# Object-Oriented Programming (OOP) 🖥️

**OOP kya hai?**  
OOP ek programming style hai jisme hum real-world objects ko represent karte hain. Isme data aur functions ko **classes aur objects** ke andar organize karte hain.  

**OOP kyun use karte hain?**  
- Complex problems ko easily solve karne ke liye  
- Code ko **organized aur readable** banane ke liye  
- Code ko **reuseable** banane ke liye (ek hi code ko baar-baar use kar sakte hain)  
- Real-world modeling ke liye (jaise car, student, bank account ko objects ke form me represent karna)  
- Maintenance aur updates easy ho jate hain, kyunki objects aur classes modular hote hain  
- Polymorphism aur Inheritance se code ko scalable aur efficient banaya ja sakta hai 💡  

## Key Concepts in OOP 🚀

### 🔵 1. Class  
- Blueprint hota hai jisse objects bante hain  
- Attributes (variables) aur methods (functions) define karte hain  

### 🔷 2. Object  
- Class ka instance hota hai  
- Methods aur attributes ko access karte hain  

### 🟢 3. Inheritance  
- Ek class doosri class se properties aur methods inherit kar sakti hai  
- Code reusability ke liye useful  

### 🟡 4. Encapsulation  
- Data ko protect karte hain using private/protected variables  
- Getter aur Setter methods ya property decorator ka use hota hai  

### 🟠 5. Polymorphism  
- Same function ya operator ka **different behavior** objects ke liye  
- Method overriding aur operator overloading iska part hain  

### 🟣 6. Decorators  
- Special functions jo methods ko modify ya enhance karte hain  
- Common: `@classmethod`, `@staticmethod`, `@property`  

### 🔺 7. Dunder (Magic) Methods  
- Special methods jo Python ke operators aur built-in functions ke behavior ko customize karte hain  
- Examples: `__str__`, `__add__`, `__len__`, `__eq__`  

---

**Summary:**  
OOP ke main benefits ye hain: **organized code, reusability, easy maintenance aur real-world modeling**. 💡
