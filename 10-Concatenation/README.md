
# ✨ String Concatenation in Python

**Definition:**
String concatenation Python me **do ya do se zyada strings ko jodne** ka process hai.

**Use:**

* Multiple strings ko **ek single string me combine** karne ke liye
* Dynamic messages aur readable output create karne ke liye

**Why We Use String Concatenation:**

* Variables aur text ko **ek saath display** karne ke liye
* **Readable aur meaningful messages** create karne ke liye



## 🔹 Key Points About String Concatenation

1. **Basic Concatenation:**

   * Strings ko `+` symbol ke through join karte hain.

2. **Adding Space Between Strings:**

   * Agar space chahiye, `" "` ka use karke strings ke beech space add karte hain.

3. **Concatenating Variables:**

   * Variables ke strings ko bhi **directly `+` se join** kar sakte hain.



✨ **Summary:**

* String concatenation = **Combine multiple strings into one** ✅
* Use `+` operator aur zarurat pade to `" "` for spacing
* Python me **dynamic text aur readable output** ke liye best practice hai
