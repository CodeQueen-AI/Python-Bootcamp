
# 🔑 Keywords in Python

✨ Keywords are special reserved words in Python.
✨ Ye wo words hain jo Python mein already defined hote hain — jinhe hum variable/function name nahi bana sakte!



## ✅ Python Keywords Program

```python
import keyword
print(len(keyword.kwlist))
print(keyword.kwlist)
```



## 📌 Important Notes

* ✅ Keywords ka specific purpose hota hai
* ❌ Inhe hum change ya redefine nahi kar sakte
* ✅ Python in keywords ki madad se program ka structure samajhta hai



## 🧠 Common Python Keywords Table (English + Urdu)

| Keyword    | Meaning (English)          | Urdu Meaning              |
| ---------- | -------------------------- | ------------------------- |
| `if`       | Condition check            | Agar                      |
| `else`     | Otherwise                  | Warna                     |
| `for`      | Loop for repeating actions | Bar bar chalne wala loop  |
| `while`    | Loop until condition       | Jab tak condition true ho |
| `True`     | Boolean true value         | Haqiqat / Sahi            |
| `False`    | Boolean false value        | Ghalat                    |
| `None`     | No value                   | Koi value nahi            |
| `and`      | Logical AND                | Aur                       |
| `or`       | Logical OR                 | Ya                        |
| `not`      | Logical NOT                | Nahi                      |
| `def`      | Function define            | Function banane ke liye   |
| `class`    | Create class               | Class banane ke liye      |
| `return`   | Function ka result dena    | Wapis karna               |
| `break`    | Loop stop                  | Loop rokna                |
| `continue` | Skip current iteration     | Agla chakkar continue     |


✨ With practice, these keywords will feel super easy! 💪
