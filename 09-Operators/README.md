# ✨ Operators in Python

**Definition:**
Operators Python me **special symbols hote hain jo values ya variables ke beech operations perform karte hain**.

**Use:**

* Calculations, comparisons, logic checks, aur data manipulation ke liye

**Why We Use Them:**

* Programming me **value manipulation aur decision making** ke liye essential hain



## 🔹 1️⃣ Arithmetic Operators

**Definition:** Numbers ke saath **mathematical operations** perform karte hain.
**Use:** Add, subtract, multiply, divide, power, remainder, floor division
**Why:** Calculations aur logic building ke liye

| Symbol | Work / Meaning      | Urdu (Simple)                                  |
| ------ | ------------------- | ---------------------------------------------- |
| `+`    | Addition            | Numbers ko jodne ke liye                       |
| `-`    | Subtraction         | Numbers me se minus karne ke liye              |
| `*`    | Multiplication      | Numbers ko multiply karne ke liye              |
| `/`    | Division            | Numbers ko divide karne ke liye (result float) |
| `**`   | Exponent / Power    | Power nikalne ke liye                          |
| `//`   | Floor Division      | Divide karke integer store karne ke liye       |
| `%`    | Modulus / Remainder | Remainder nikalne ke liye                      |


## 🔹 2️⃣ Assignment Operators

**Definition:** Variables ki **value update ya assign** karte hain
**Use:** Variable ko assign, update ya modify karne ke liye
**Why:** Code short aur efficient banane ke liye

| Symbol | Work / Meaning        | Urdu (Simple)                             |
| ------ | --------------------- | ----------------------------------------- |
| `=`    | Assign                | Value dene ke liye                        |
| `+=`   | Add & Assign          | Value add karke store karne ke liye       |
| `-=`   | Subtract & Assign     | Value minus karke store karne ke liye     |
| `*=`   | Multiply & Assign     | Multiply karke store karne ke liye        |
| `/=`   | Divide & Assign       | Divide karke store karne ke liye          |
| `%=`   | Modulus & Assign      | Remainder store karne ke liye             |
| `**=`  | Power & Assign        | Power calculate karke store karne ke liye |
| `//=`  | Floor Divide & Assign | Divide karke integer store karne ke liye  |



## 🔹 3️⃣ Bitwise Operators

**Definition:** Numbers ke **binary bits pe operations** karte hain
**Use:** Binary calculations ya manipulation ke liye
**Why:** Low-level programming aur efficient calculation ke liye

| Symbol | Work / Meaning | Urdu (Simple)                   |                               |
| ------ | -------------- | ------------------------------- | ----------------------------- |
| `&`    | AND            | Dono bits 1 ho tab 1 return     |                               |
| `      | `              | OR                              | Koi bhi bit 1 ho tab 1 return |
| `^`    | XOR            | Sirf ek bit 1 ho tab 1 return   |                               |
| `~`    | NOT            | Bits ka opposite karne ke liye  |                               |
| `<<`   | Left Shift     | Bits left shift (multiply by 2) |                               |
| `>>`   | Right Shift    | Bits right shift (divide by 2)  |                               |



## 🔹 4️⃣ Comparison Operators

**Definition:** Do values ko **compare** karte hain
**Use:** Decision making me True/False result ke liye
**Why:** Logic aur conditions me use hota hai

| Symbol | Work / Meaning   | Urdu (Simple)             |
| ------ | ---------------- | ------------------------- |
| `>`    | Greater than     | Bada hai ya nahi check    |
| `<`    | Less than        | Chota hai ya nahi check   |
| `==`   | Equal to         | Barabar hai ya nahi check |
| `!=`   | Not equal to     | Barabar nahi hai check    |
| `>=`   | Greater or equal | Bada ya barabar check     |
| `<=`   | Less or equal    | Chota ya barabar check    |



## 🔹 5️⃣ Identity Operators

**Definition:** Variables ke **memory location same hai ya nahi** check karte hain
**Use:** Same object check karne ke liye
**Why:** Memory-level comparison me help karta hai

| Symbol   | Work / Meaning  | Urdu (Simple)                   |
| -------- | --------------- | ------------------------------- |
| `is`     | Same object     | Same memory location check      |
| `is not` | Not same object | Different memory location check |



## 🔹 6️⃣ Membership Operators

**Definition:** Element collection me **exist karta hai ya nahi** check karte hain
**Use:** Lists, sets, strings me presence/absence check
**Why:** Data ke andar element ko verify karne ke liye

| Symbol   | Work / Meaning | Urdu (Simple)             |
| -------- | -------------- | ------------------------- |
| `in`     | Check presence | Element hai ya nahi check |
| `not in` | Check absence  | Element nahi hai check    |



## 🔹 7️⃣ Logical Operators

**Definition:** Multiple conditions ko **combine** karte hain
**Use:** Complex conditions aur decisions ke liye
**Why:** Logical reasoning aur program flow control ke liye

| Symbol | Work / Meaning | Urdu (Simple)                        |
| ------ | -------------- | ------------------------------------ |
| `and`  | Both True      | Dono conditions True honi chahiye    |
| `or`   | Either True    | Ek condition True ho toh result True |
| `not`  | Reverse        | Condition ka opposite result         |
