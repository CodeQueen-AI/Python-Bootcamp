# 🧾 Lists in Python



A **List** Python mein ek aisi data structure hai jisme multiple values ko ek hi variable mein store kiya ja sakta hai. List ke andar numbers, strings, ya mixed values ho sakti hain. ✅

## Creating Lists 🟢

* Normal list create kar sakti ho.
* Empty list create karna possible hai.
* Constructor `list()` ka use bhi kar sakti ho.

## Length of a List 📏

* `len()` function se list ka length check kar sakti ho.
* Ye batata hai ke list me kitne elements hain.

## Adding and Modifying List Elements ➕

* **append()**: List ke end me naya element add karta hai.
* **insert()**: Specific index par element add karta hai.
* Index ke through existing elements ko modify kar sakti ho.

## Slicing and Deleting Elements ✂️

* Slicing se list ke parts access kar sakti ho.
* **del**: Index se element delete karta hai.
* **remove()**: Value se element delete karta hai.
* **pop()**: Last element remove kar ke return karta hai.
* **clear()**: List ke saare elements remove kar deta hai.

## Copying Lists 📋

* Lists ko copy karke original safe rakha ja sakta hai.
* Modifications copy pe ki ja sakti hain without affecting original.

## Indexing & Slicing 🔢

* Positive aur negative indexing available hai.
* Slicing se multiple elements ek saath access kar sakti ho.

## Sorting and Reversing 🔄

* Lists ko ascending ya descending order me sort kiya ja sakta hai.
* **reverse()** ya slicing se list reverse ki ja sakti hai.

## Map and Filter 🧮

* **map()**: List ke har element pe function apply karta hai.
* **filter()**: Specific condition ke elements filter karta hai.

## Nested Lists 🥝

* List ke andar dusri list bhi ho sakti hai.
* Hierarchical ya grouped data store karne ke liye useful hota hai.

## Why Use Lists? 💡

* Multiple values ko single variable me store karna easy hai.
* Ordered collection, items index se access kiye ja sakte hain.
* Mutable (changeable) - add, remove, modify possible hai.
* Mixed data types ek hi list me rakhe ja sakte hain.
* Iteration easy hai aur operations like sorting, filtering, mapping perform karna simple hai.
