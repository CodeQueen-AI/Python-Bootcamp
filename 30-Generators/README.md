# 📘 **README – Understanding Generators**

### ⭐ **What Is a Generator?**

Generator aik special function hota hai jo **ek-ek value** return karta hai, aur har value ke beech mein function **pause** ho jata hai.
Next call par generator wahi se continue karta hai jahan ruk gaya tha.

Roman Urdu:
Generator aik function hai jo step-by-step values deta hai aur memory efficient hai.

---

### ⭐ **Why Do We Use Generators?**

* Boht bade data sets ko efficiently handle karne ke liye
* Ek-ek value ko step-by-step process karne ke liye
* Memory bachane ke liye
* Loops aur iterations ko easy aur clean banane ke liye

Roman Urdu:
Generators hamesha memory save karte hain aur data ko ek-ek karke process karne dete hain.

---

### ⭐ **How Do Generators Work?**

* Function ke andar **`yield`** statement use hota hai
* Jab generator call hota hai, pehli value return hoti hai
* Next time `next()` call hota hai, function resume hota hai jahan `yield` pe ruk gaya tha
* Jab saari values exhausted ho jati hain, generator finish ho jata hai

Roman Urdu:
`yield` ek-ek value deta hai aur function ko temporarily rok deta hai. Next call pe wapas resume hota hai.

---

### ⭐ **Where Are Generators Used?**

* Large files read karne ke liye
* Loops ke andar step-by-step calculations ke liye
* Streams aur sequences process karne ke liye
* Memory-intensive operations me

Roman Urdu:
Generators ko tab use karte hain jab humein bohot bara data ek sath nahi lena, balki step-by-step chahiye hota hai.

---

### ⭐ **Short Summary**

* Generator = ek-ek value dene wala function
* `yield` statement values ko step-by-step return karta hai
* Function pause aur resume hota hai
* Memory-efficient aur loop-friendly hai
* Large data sets aur streams ke liye best practice
