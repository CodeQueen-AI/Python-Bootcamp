# Python Operator Precedence (PEDMAS) Guide ⚡

**PEDMAS** ka matlab hai:
**Parentheses → Exponents → Multiplication/Division → Addition/Subtraction**

Python me ye decide karta hai ke **kaunsa operation pehle execute hoga aur kaunsa baad me**. 🔢

---

## **1. Addition & Multiplication ➕✖️**

* Multiplication pehle hota hai, phir addition.
* Parentheses use karne se order change hota hai aur output different hota hai. 🔄

---

## **2. Subtraction & Division ➖➗**

* Division pehle hoti hai, phir subtraction.
* Parentheses se calculation clear aur predictable ban jata hai. ✅

---

## **3. Exponents + Addition/Subtraction **

* Exponentiation (`**`) sabse pehle hoti hai. 🔺
* Uske baad addition aur subtraction calculate hoti hai.
* Parentheses se complex expressions ka result control kiya ja sakta hai. 🎯

---

## **4. Complex Expressions 🧩**

* Without parentheses, Python PEDMAS follow karta hai.
* Parentheses use karne se **expression readable aur predictable** ho jata hai. 👀

---

## **Quick PEDMAS Reminder 📝**

1. **P** → Parentheses `()`
2. **E** → Exponents `**`
3. **D / M** → Division `/`, Multiplication `*`, Floor Division `//`, Modulus `%`
4. **A / S** → Addition `+`, Subtraction `-`

**Tip:** Hamesha parentheses use karo taake complex expressions me confusion na ho aur output predictable ho. 💡
