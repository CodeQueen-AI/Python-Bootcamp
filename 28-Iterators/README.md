# 📘 **README – Understanding Iterators**

### ⭐ **What is an Iterator?**

Iterator aik aisi cheez hoti hai jo list ya collection se items **ek ek karke** deti hai.
Yani ek mechanism jo data ko step-by-step nikal kar deta hai.

---

### ⭐ **Why Do We Use Iterators?**

Iterators is liye use hote hain taa ke hum:

* Data ko ek ek karke hasil kar saken
* Large lists ko efficiently handle kar saken
* Memory kam istemal ho
* Har value ko sequence mein access kar saken
* Loops aur functions ko smooth bana saken

Yani jab hamein slow, controlled tareeke se values chahiye hoti hain to iterator bohot useful hota hai.

---

### ⭐ **How Does an Iterator Work?**

Iterator ka kaam bohot seedha hota hai:

* Pehle hum list ko iterator bana dete hain
* Phir har dafa "next" lene par iterator **agla element** de deta hai
* Jab elements khatam ho jaate hain to iterator ruk jata hai

Yani yeh system har dafa ek naya item return karta jata hai.

---

### ⭐ **Where Are Iterators Used?**

Iterators bohot jagahon par use hote hain, jaise:

* Lists aur arrays
* Loops (jaise for-loop)
* Functions ke andar
* Generators ke sath
* Step-by-step data processing mein

Jahan bhi sequential access chahiye ho, wahan iterator kaam aata hai.

---

### ⭐ **Why Do Loops Use Iterators Automatically?**

For-loop khud hi background mein iterator use karta hai.
Is liye hume manually iterator banane ki zaroorat nahi hoti.

For-loop ek ek element list se nikal kar deta jata hai — yeh sab iterator ki wajah se hota hai.

---

### ⭐ **Why Use an Iterator Inside a Function?**

Functions ke andar iterator is liye use hota hai taa ke:

* Data ko controlled tareeke se handle kiya ja sake
* Function har value ko alag alag process kare
* Code clean aur understandable rahe
* Steps predictable rahen

Yani function ko poora control mil jata hai ke kis waqt kaunsi value leni hai.

---

### ⭐ **Short Summary**

* Iterator = ek ek item dene wala system
* Step-by-step values ko handle karne ke liye best
* For-loop khud iterator use karta hai
* Functions ke andar clarity aur control milta hai
