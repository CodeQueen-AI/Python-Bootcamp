# 🔁 Loops in Python

## 📘 What are Loops?

**Loops** programming ka ek tool hai jo **ek kaam ko bar-bar repeat** karne ke liye use hota hai.
Isse hum **time aur effort bacha sakte hain**, aur repetitive tasks efficiently handle kar sakte hain.

---

## 🔹 Types of Loops

### 1. **For Loop**

* **For loop** use hota hai jab hume pata ho ke **kitni dafa kaam repeat karna hai**.
* Example: Ek sequence ya range of numbers par iterate karna.

---

### 2. **While Loop**

* **While loop** use hota hai jab hume kaam **tab tak repeat karna ho jab tak koi condition true ho**.
* Example: Jab tak count 5 se chhota ya barabar hai, task repeat hota rahe.

---

### 3. **Nested Loop**

* **Nested loop** matlab ek loop ke andar **dusra loop**.
* Useful hota hai **2D data** ya combinations ke liye.
* Example: Ek grid ya table ke rows aur columns par iterate karna.

---

## 🔹 Control Statements in Loops

Loops ke andar hum kuch special **control statements** use kar sakte hain jo loop ka behaviour change karte hain:

1. **Break**

   * Loop ko **immediately stop** kar deta hai.
   * Example: Agar condition meet ho jaye, loop ruk jaye.

2. **Continue**

   * Loop ke **current iteration ko skip** kar deta hai aur next iteration pe chala jata hai.
   * Example: Agar number 3 ho to skip karke next number print kare.

3. **Pass**

   * **Kuch nahi karta**, sirf placeholder ke liye use hota hai.
   * Example: Loop ke andar condition ke liye koi action nahi chahiye, lekin syntax khatam nahi karna.

---

## 🔹 Real-World Example

* Agar hum **numbers 1 se 10** iterate karte hain aur:

  * 3 pe **continue** → skip
  * 7 pe **pass** → kuch nahi hoga
  * 9 pe **break** → loop ruk jayega

To ye demonstrate karta hai ki loops aur control statements **milke kaise flexible aur powerful bante hain**.

---

## ✨ In Short

**Loops = Repetition ka tool**
**Control Statements = Loop ke behavior ko modify karne ke tool**
Ye dono programming mein **time aur effort bachane** ke liye bohat important hain.
