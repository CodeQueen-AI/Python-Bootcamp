# Inheritance in Python 🌳

**Inheritance kya hai?**
Inheritance ek OOP concept hai jisme ek class (child) doosri class (parent) ki properties aur methods ko **reuse kar sakti hai**.
Iska matlab hai ke code ko **dobara likhne ki zarurat nahi** padti aur program organized hota hai. ✨

**Inheritance kyun use karte hain?**

* Code ko **reusable** banane ke liye
* Complex programs ko **organized aur modular** banane ke liye
* Parent class ke methods aur attributes ko **child class me directly use** karne ke liye
* Program ko **scalable aur maintainable** banane ke liye
* Real-world objects ke **relationship model** karne ke liye

---

## 🔹 Types of Inheritance

### 1️⃣ Single Inheritance

* Ek child class sirf **ek parent class** se inherit karti hai.
* Simple aur most common scenario hai.
* Reusability aur code organization ke liye use hota hai.

### 2️⃣ Multiple Inheritance

* Ek child class **ek se zyada parent classes** se inherit kar sakti hai.
* Parent classes ke methods aur attributes combine hoke child class me available hote hain.
* Complex programs me powerful tool hai.

### 3️⃣ Constructor Inheritance

* Child class **parent ka constructor** call kar sakti hai using `super()` function.
* Object banate waqt parent class ka initialization automatic hota hai.
* Ye ensure karta hai ke **parent ke data aur setup bhi use ho** rahe hain.

### 4️⃣ Hierarchical Inheritance

* Ek **parent class** ke multiple **child classes** ho sakte hain.
* Har child apni functionalities ke saath parent ke features inherit kar sakta hai.
* Real-world modelling me, jaise ek `Vehicle` class se `Car`, `Bike`, `Bus` inherit karna.

### 5️⃣ Hybrid Inheritance

* Single + Multiple + Hierarchical inheritance ka **combination**.
* Complex scenarios me use hota hai jab **alagalag inheritance types ko combine** karna ho.

---

## 🔹 Features in Inheritance

### 1️⃣ Method Overriding

* Child class parent class ke method ko **apne hisaab se redefine** kar sakti hai.
* Parent ke behavior ko change karna ya extend karna easy ho jata hai.
* Real-world example: `Animal` class me `sound()` method, `Dog` class me customize.

### 2️⃣ Method Resolution Order (MRO)

* Python decide karta hai **kis parent class ka method pehle call hoga**.
* Ye especially **Multiple aur Hybrid inheritance** me important hai.
* `super()` aur MRO ka sahi use program ke correct behavior ke liye zaruri hai.

### 3️⃣ `super()` Function

* Parent class ke methods aur constructors ko call karne ke liye use hota hai.
* Ye inheritance ke concepts ko **clean aur maintainable** banata hai.

---

## 🔹 Summary 🌟

* Inheritance = Parent-child relationship aur **code reuse** ka concept 🌳
* Types = Single, Multiple, Constructor, Hierarchical, Hybrid
* Features = Method Overriding, MRO, `super()`
* Benefits = **Organized code, scalable programs, easy maintenance aur real-world modeling**
