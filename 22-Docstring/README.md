# 🐍 Python Docstring

## 📘 What is a Docstring?

Docstring ka matlab hai **Documentation String**.
Ye ek special comment hota hai jo function, class ya module ke andar likha jata hai taake wo explain kare **ye code kya karta hai**



## 💡 Why We Use Docstring

Docstring is liye use hoti hai taake:

* Function ya class ka purpose samajhne mein asani ho
* Code ko readable aur professional banaya ja sake
* Kisi aur developer ko samajh aaye ke ye function kya karta hai aur kaise use hota hai



## 🔹 How It Works

Docstring **triple quotes (`""" ... """`)** ke andar likhi jati hai.
Ye function ke andar likhne ke baad automatic store ho jati hai aur usay access karne ke liye
`function_name.__doc__` likhte hain



## 🧠 Example Explanation

Agar koi function do numbers ka sum nikalta hai, to docstring batayegi ke:

* Function ka naam kya hai.
* Uske parameters kya hain (jaise `a` aur `b`).
* Function kya return karega (jaise unka sum).


## ✨ In Short

**Docstring** ek tarha ka note hai jo code ke andar likha jata hai taake ye bataye
ke **function, class ya module ka purpose kya hai** aur **kaise kaam karta hai**.
