## ✅ Conditional Statements in Python

Conditional statements program ko decision lenay ki ability dete hain.
Agar condition True ho to specific code run hota hai ✅ aur False ho to nahi hota ❌



### 🔹 1️⃣ If Statement

Sirf ek condition ko check karta hai.
Urdu: Agar condition sahi ho to code run hota hai.



### 🔹 2️⃣ If-Else Statement

2 possibilities:
Urdu: Agar condition sahi ho to aik block, warna doosra block run hota hai.



### 🔹 3️⃣ If-Elif-Else Statement

Multiple conditions check karta hai.
Urdu: Agar bohat saari conditions check karni hon to elif use hota hai.



### 🔹 4️⃣ Nested If Statement

Ek If ke andar doosra If hota hai.
Urdu: Condition ke andar condition check hoti hai, pehli condition sahi honi chahiye.



### ⭐ Short Summary

| Type         | Use                      | Urdu                         |
| ------------ | ------------------------ | ---------------------------- |
| if           | Single condition         | Agar                         |
| if-else      | True ya False dono cases | Agar nahi to                 |
| if-elif-else | Multiple conditions      | Kay sare check               |
| nested if    | If ke andar If           | Condition ke andar condition |
