
## 🌟 Escape Sequences in Python

Escape sequences wo special codes hote hain jo **print** statement ke andar text ko control karne ke kaam aate hain
Ye **backslash \** se start hote hain aur output ka format change kar dete hain.



### 🔹 Common Escape Sequences

| Escape Sequence | Meaning (English) | Urdu + Simple Description                         |
| --------------- | ----------------- | ------------------------------------------------- |
| `\n`            | New line          | Nayi line start karta hai                         |
| `\t`            | Tab space         | Beech mein extra space deta hai (table jaisa gap) |
| `\\`            | Backslash         | Backslash character print karta hai               |
| `\'`            | Single quote      | String ke andar single quote likhne ke liye       |
| `\"`            | Double quote      | String ke andar double quote likhne ke liye       |
| `\r`            | Carriage return   | Line ki starting se output replace karta hai      |
| `\b`            | Backspace         | Ek character peeche delete jaisa effect           |
| `\f`            | Form feed         | Nayi page jaisa effect (rarely used)              |



### ✅ Quick Notes

* Escape sequences formatting ko control karte hain
* Jaise **new line**, **spaces**, **quotes**, **special effects**, etc
* Most used: `\n`, `\t`, `\"`, `\\`
